# ADR format

Use the project's established location, numbering, and format first. Otherwise
place records in `docs/adr/NNNN-slug.md`, choosing the next unused number.
Create the directory only when an actual decision needs recording.

```markdown
# Decision title

The situation, the decision, and why it was chosen in one to three sentences.
```

Add status, alternatives, or consequences when they help a future reader
understand a real trade-off. Distinguish a proposed decision from one accepted by
its owner. The criteria for offering an ADR are in [domain guidance](domain.md).
